ITER

ITER Limiter Work — Recognition and Revised Direction

People: Andrei Pshenov, Xavier Bonnin, Richard Pitts

Conference outcome

  • The previous ITER limiter SOLPS-ITER simulations were cited in two separate invited talks, confirming the work is high-visibility.
  • Agreement to further this work; specific approach clarified in post-conference email from Andrei (2026-05-29).

Revised plan — from Andrei's email (2026-05-29)

  • Wide-grid (WG) approach is de-prioritised. No converged WG limiter cases exist on the cluster. Andrei has only worked on narrow-grid limiter geometry for WHA assessment. The Eirene surfmode-split functionality needed for spatially dependent prompt redeposition in WG is also not yet available.
  • New approach: fluid neutrals on existing narrow-grid cases. Run a fluid neutral scan (with and without prompt redeposition) on the existing narrow-grid limiter setup. The fluid neutral model already has a self-consistent prompt redeposition implementation — no Eirene surfmode splitting needed.
  • Kinetic neutral effects are expected to be negligible in this plasma regime.
  • If fluid neutral results are consistent with kinetic neutral results → the door opens for time-dependent simulations (kinetic neutrals would make this computationally infeasible). This is identified as the main scientific priority.
  • WG remains a future option only if an equilibrium is selected where plasma is close to both the HFS and LFS walls simultaneously.

Action items

  • ☑ Follow up with Andrei post-conference — done, email received 2026-05-29
  • ☐ Set up fluid neutral scan on existing narrow-grid limiter cases (with / without prompt redeposition).
  • ☐ Compare fluid vs. kinetic neutral results; report to Andrei.
  • ☐ If results are consistent: plan time-dependent limiter phase simulations.

TCV Team — NT + XD Configuration Concept

Source: TCV experimental team presentation

Key finding

  • TCV demonstrated a combined NT + XD configuration in the outer targets (SN): maintains high core performance (from NT) while easing detachment onset at the outer target (from XD).
  • CFS / SPARC has proposed using DN + XD in both upper and lower outer divertors, creating 8 strike points.
  • This raises the question: could a DN + XD + NT configuration be studied in predictive simulation? This is a non-trivial but potentially high-impact direction.

Action items

  • ☐ Evaluate feasibility of a predictive DN+XD+NT simulation study; discuss with TCV and CFS contacts.
